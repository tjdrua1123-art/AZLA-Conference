# v0.4 검증 보고서

2026-11-04. 작성/취합 화면의 가독성, 전주 자료를 이어 쓰는 다음 주 회의, 주차별 안건 삭제·복원을 개선했습니다. 여섯 분류 탭과 회의 전체 녹음/자동 요약 흐름은 유지합니다.

- TypeScript 검사, 프로덕션 빌드 통과.
- 단위/실제 PostgreSQL 엔진(PGlite) 통합 테스트 22개 통과: 분류 순서, 이전 데이터 호환, 공동 수정 병합·충돌, 서버 전용 DB 권한, AI 한도, 녹음 단계별 저장·실패 후 재시작·긴 전사 분할 검사. 기존 v0.1 정책 검사도 유지합니다.
- 프로덕션 빌드 대상 Chromium 브라우저 검증 통과. 탭 전환 및 가속한 4분 경계에서 두 녹음 구간이 순서대로 저장·정리됨을 확인했습니다. 브라우저 테스트는 실제 Chromium MediaRecorder와 가상 마이크를 사용하며, OpenAI 응답은 테스트용으로 제어합니다. 각 탭의 내용 분리·입력/수정·이미지 검토·탭 이동 중 녹음·회의 종료 자동 처리·요약 영속화·실패 후 재시도·원본 포함 ZIP 복원·동시 편집·마이크 거부·모바일을 검사합니다.
- 실제 OpenAI API, 호스팅 Supabase Storage/DB, 회의실 장비와 장시간 실녹음은 아직 미검증입니다. 테스트용 AI 응답을 실제 전사 정확도 검증으로 주장하지 않습니다. 운영 배포 성공도 Git 푸시와 별도로 확인해야 합니다.

## 이번 변경의 추가 검증

- 1366×768 PC: 진행 내용/다음 계획/회의 결정의 가로 배치, 입력 창 외부 스크롤 없이 저장 버튼 노출, 저장 후 편집 지속, Ctrl/Cmd+S 반복 저장 후 첨부 보존을 확인했습니다.
- 취합 화면: 전체 문서 세로 스크롤 대신 본문 영역 확보, 긴 내용 펼치기/접기, 전주 대비 변경 강조와 나란히 비교, 새로고침 후 수정 내용 유지, 모바일 가로 넘침 방지를 확인했습니다.
- 다음 주 생성: 보고·계획·결정·첨부 원본 경로 유지, 주차별 별도 ID, 녹음 제외, 이미 준비된 주 재사용과 수정 보존, 삭제한 안건의 이월 제외를 확인했습니다. 날짜를 변경한 준비 회의의 재사용과 두 직원의 동시 생성은 모델 테스트로 검사했습니다.
- 안건 삭제/복원: 해당 주차의 목록에서 제외, 휴지통 복원, 파일 접근 유지, 원래 주차 불변을 브라우저에서 확인했습니다. 삭제와 동시 내용 수정의 충돌도 단위 테스트로 검사했습니다.
- 공유 링크 접근/서명 쿠키/잘못된 입력 거부는 별도 로컬 서버와 테스트용 자격증명으로 통과했습니다. 실제 Supabase 호출을 대체하는 검증은 아닙니다.

`npm run test:readability`는 `TEST_BASE_URL`로 지정한 실행 서버를 검사합니다. 스크린샷은 `/tmp`에만 생성하며 공개 Git 저장소에 실제 회의자료를 포함하지 않습니다.
