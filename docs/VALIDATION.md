# v0.2 검증 보고서

2026-11-04. 계정 로그인을 제거하고 담당자 공동 작성, PPT 가져오기와 디자인 컨펌 흐름으로 변경했습니다. 제공 PPT의 구조를 참고했으며 실제 원문/이미지는 공개 저장소에 포함하지 않았습니다.

## 로컬 검증

- TypeScript 검사와 Next.js 프로덕션 빌드 통과.
- 단위/실제 PostgreSQL 엔진(PGlite) 통합 테스트 13개 통과. v0.1 보호 정책 회귀 검사도 유지합니다.
- 공동 작성: 서로 다른 안건/필드는 합치고 같은 필드의 경쟁 수정은 충돌로 처리, 후속 업무 중복 방지 및 같은 ID로 이월, 검토 이력 누적, 검토 전 확정 차단을 검사합니다.
- 신규 SQL은 anon/authenticated 직접 데이터 접근 차단, 서비스 역할 저장, 원자적 버전 검사·수정 이력, 팀 AI 일일 40회 제한과 private bucket을 검사합니다.
- Chromium 브라우저 검증 통과: 계정 없이 생성/편집/저장/재열람, 이미지 첨부·수정 요청, 두 시안 비교, 회의 모드, 업무 이월, 두 탭의 병합/충돌, 사진 포함 ZIP 백업, 모바일, 이전 로그인 경로 리다이렉트.
- 실제 제공된 39장 PPT의 페이지 순서·업무 보고/업무 계획 표·원본 이미지 가져오기 통과(39페이지, 23개 이미지). 파일은 로컬 테스트 입력으로 사용합니다. 파일은 저장소에 넣지 않습니다.

- `npm run test:access` 통과: 실제 키 대신 로컬 fixture를 사용하는 별도 서버에서 공유 링크 없는 접근 차단, 틀린 키, Origin 검사, HttpOnly 세션, URL fragment 제거와 잘못된 입력 거절을 확인합니다. 호스팅 Supabase에 요청하지 않습니다.

## 외부 서비스 범위

Supabase 서비스 키와 공유 키, OpenAI 키가 없어 실제 호스팅된 DB/Storage의 공유 저장과 전사/AI 호출, Vercel 운영 배포는 검증하지 않았습니다. 브라우저 로컬 저장과 DB 엔진 테스트는 실제 Supabase HTTP/Auth/Storage 연결을 대체하지 않습니다. 실제 담당자들의 공동 사용은 `SETUP.md`의 공유 설정과 `OPERATIONS.md`의 인수 테스트 후 확인해야 합니다.
