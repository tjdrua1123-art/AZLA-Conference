# AZLA 주간회의 워크스페이스

매주 회의록, 제품 개발 이력, 후속 업무를 한곳에서 관리하는 한국어 사내 웹 프로그램입니다. **Next.js · React · TypeScript + Supabase(DB/Auth/비공개 Storage) + OpenAI**로 구성하며 다른 DB나 파일 저장 서비스를 사용하지 않습니다.

## 빠른 실행

Node.js 22 이상이 필요합니다(현재 클라우드는 24). 프로젝트 폴더에서:

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Supabase 공개 환경변수를 비워두면 **읽기 전용 샘플 미리보기**가 나타납니다. 샘플은 실제 직원·제품 개발 데이터가 아니고 DB에 저장하지 않습니다. 실제 연결 환경에는 샘플 데이터가 섞이지 않습니다. 공개 URL과 publishable key를 모두 설정하면 직원 인증이 필요합니다. 비밀번호와 실제 API 키를 Git에 커밋하지 마세요.

## 구현 기능

- 한국어 대시보드, 회의 날짜/제품/키워드 검색, 제품별 회의·업무 이력
- 회의 생성(월요일 기본값), 편집, 명시적 임시저장, 검토 확인 후 확정, 브라우저 인쇄/PDF
- 회의 저장 버전과 원본 스냅샷, 낙관적 잠금으로 동시 저장 충돌 감지
- JPG/PNG/WebP 미리보기·확대, PDF·녹음파일 업로드/다운로드(20MiB), 비공개 Storage·60초 서명 URL
- HTTPS 브라우저 녹음, 기존 녹음 업로드, 한국어 전사
- 메모+전사 기반 AI 초안, 원문 근거 표시, 담당자/일정 미정 처리, 사용자 검토 후 반영
- 업무 담당자/예정일/상태, 회의 생성 시 이전 회의 미완료 업무 자동 연결, 동일 업무 복제 방지
- 관리자/작성자/열람자 RLS, 초대 전용 직원 관리, 비활성 직원 데이터 접근 차단
- AI 사용 기록·원자적 일일 요청 한도, 토큰 기록(요약), 원본 기록 보존

**범위:** 회의 생성은 사용자 동작이며 월요일 예약 생성 서버는 포함하지 않습니다. 자동저장이 아닌 임시저장 버튼 방식입니다. AI 업무 제안은 검토 후 업무 탭에 직접 등록합니다. 업무 이력은 DB에 보관하고 제품 화면은 현재 상태를 표시합니다. 삭제 기능은 장기 보관을 위해 의도적으로 제공하지 않습니다.

## 연결과 운영

1. [Supabase 및 Vercel 설정](docs/SETUP.md)을 따라 새 Supabase 프로젝트에 `supabase/schema.sql`을 한 번 실행합니다.
2. Auth 외부 회원가입을 끄고 첫 관리자를 등록합니다.
3. `.env.example` 기준으로 실제 환경변수를 로컬 또는 Vercel에 입력합니다.
4. [운영 전 점검 및 백업](docs/OPERATIONS.md)의 실제 서비스 테스트를 수행합니다.

```bash
npm run typecheck
npm test
npm run build
npm start
# 별도 터미널: Chromium이 설치된 환경에서, Supabase 미설정 샘플 화면 검증
npm run test:browser
```

브라우저 테스트는 기본 `/usr/bin/chromium`을 사용하며 `CHROMIUM_PATH`로 바꿀 수 있습니다. 로컬 검증 결과와 외부 연결 미검증 사항은 [검증 보고서](docs/VALIDATION.md)를 확인하세요. Supabase Pro 프로젝트 생성/결제, 운영 DB 적용 및 Vercel 운영 배포는 이 코드 작성 과정에서 실행하지 않았습니다.
