# AZLA 주간회의 · 디자인 검토 워크스페이스

제품별 업무 보고, 다음 계획, 대표님 디자인 컨펌과 후속 업무를 한 회의록에서 함께 작성합니다. **계정 로그인과 직원 가입 기능을 제거**했습니다. 담당자는 기록과 필터에 사용하는 이름을 직접 입력합니다.

## 주요 흐름

1. 새 주간회의를 만들거나 기존 `.pptx`를 가져옵니다.
2. 안건마다 제품명, 담당자, 협력업체를 지정합니다. 각 담당자가 같은 공유 링크에서 자신의 업무 보고·다음 계획을 작성합니다.
3. 시안 이미지를 크게 보거나 두 장을 비교하고, 검토자·승인/수정 요청·구체적 의견을 기록합니다.
4. 회의 모드에서 안건과 이미지를 차례로 확인합니다. ←/→ 이동, Esc 종료.
5. 후속 업무에 담당자와 기한을 지정하고 **회의 저장**을 누릅니다. 다음 주 회의 준비 시 지난 보고와 미완료 업무를 이어갑니다.

첨부된 회의 PPT의 업무 보고/업무 계획, 제품 진행 현황, 협력업체 및 이미지 검토 구조를 참고했습니다. **실제 회의자료·원본 이미지·인명·거래 조건은 저장소에 포함하지 않았습니다.** 사용자가 앱에서 가져옵니다.

## 빠른 실행

Node.js 22 이상(개발·검증 24), 프로젝트 루트에서:

```bash
npm ci
npm run dev
```

환경변수가 없으면 바로 작성 가능한 **브라우저 로컬 저장**입니다. 샘플이 아니며 입력한 회의록과 이미지를 IndexedDB에 보관합니다. 다른 직원의 브라우저와는 공유되지 않습니다. 사이트 데이터 삭제·다른 기기 이동 시 자동 복원되지 않으므로 사진 포함 ZIP 백업을 내보내세요.

**담당자들이 함께 쓰려면 [팀 공유 설정](docs/SETUP.md)을 완료해야 합니다.** DB와 비공개 파일은 Supabase 하나에서 보관하고, Vercel 서버가 공유 링크를 확인합니다. Supabase Auth는 사용하지 않으며 RLS를 공개하지 않습니다. 링크를 받은 사람은 모두 열람·수정할 수 있고 역할 구분은 없습니다.

## 저장과 동시 작성

명시적 저장 버튼 방식이며 `Ctrl/Cmd+S`도 지원합니다. 저장하지 않은 변경은 표시하고 탭 종료 시 알립니다. 저장 시점의 버전이 다르면 변경하지 않은 항목과 다른 담당자의 수정은 3방향 병합합니다. 같은 필드를 서로 다르게 수정하면 자동 덮어쓰기를 막고 현재 입력을 유지합니다. 이 경우 백업을 내보낸 뒤 최신 자료와 비교하세요. 원격 수정은 ‘최신 불러오기’ 또는 저장 시 병합으로 반영되며 실시간 커서/공동 타이핑 기능은 아닙니다.

## 자료 가져오기와 디자인 검토

- PPTX: 페이지 순서, 텍스트, JPG/PNG/WebP 원본 이미지를 가져옵니다. ‘업무 보고 / 업무 계획’ 표는 별도 작성란으로 나눕니다. 가져올 페이지를 선택하고 제품명·담당자는 직접 확인합니다.
- PPT 전체 슬라이드 렌더러가 아닙니다. 도형/차트/애니메이션/원본 배치와 이미지 자르기는 재현하지 않습니다. 기존 PPT에서 승인된 것으로 보이는 내용도 새 이미지의 승인 상태로 자동 추론하지 않습니다.
- 시안별 이름·승인 상태·수정 요청·검토자·시각·이력을 보관합니다. 직접 입력한 검토자 이름은 본인 인증이나 전자서명이 아닙니다.
- 파일당 20MiB, PPT/백업 입력 100MiB. 지원 형식: JPG/PNG/WebP, PDF, 지정된 오디오 형식. 이미지/PDF/녹음 원본을 보존합니다.
- 인쇄/PDF는 회의 전체 안건, 시안과 컨펌 내용, 후속 업무를 출력합니다. 인쇄 전에 이미지가 모두 표시되는지 확인하세요.

## AI와 녹음

브라우저 녹음과 녹음파일 첨부는 로컬에서도 사용합니다. 전사/AI 초안은 **팀 공유 저장소 + OpenAI 키** 연결 후 제공됩니다. 메모·현재 안건·전사를 함께 정리하고 근거 인용을 검증합니다. 초안 반영과 업무 등록은 사용자가 검토한 뒤 별도로 수행합니다. AI는 자동 확정하지 않습니다. 팀 전체 한국시간 하루 40회 제한(실패 요청 포함)이 있으며 정확한 금액 상한은 아닙니다.

## 검증

```bash
npm run typecheck
npm test
npm run build
npm start
# 다른 터미널. Chromium 필요, 기본 /usr/bin/chromium
npm run test:browser
# 별도 로컬 테스트 서버로 공유 링크 보호 검사 (포트 3101 사용)
npm run test:access
```

`CHROMIUM_PATH`, `TEST_BASE_URL`로 실행 환경을 변경할 수 있습니다. `AZLA_REFERENCE_PPTX`에 로컬 PPT 경로를 주면 제공된 39페이지 회의자료의 가져오기 검증도 수행합니다. 테스트에 원본 자료를 커밋하지 않습니다.
